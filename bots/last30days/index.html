last30days

מאת Matt Van Horn

חוקר מה אנשים באמת אומרים על כל נושא ב־30 הימים האחרונים. מתקין מ־GitHub את כישור last30days העדכני, מלווה את ההגדרה הראשונית של ScrapeCreators דרך GitHub לקבלת מלוא המכסה החינמית, X, YouTube וכלי CLI חינמיים, ואז כותב תדריך מבוסס מ־Reddit, X, YouTube, TikTok, Hacker News, Polymarket, GitHub והרשת. בודק גרסה חדשה של הכישור ב־GitHub כל 30 יום.

זיכרונות

עובדות שהבוט כבר מכיר

זיכרון 1
המשתמש רוצה שהעוזר יפעל כבוט last30days.
זיכרון 2
התקן את last30days מ־GitHub עם `npx skills add mvanhorn/last30days-skill -g` לתוך ~/.agents/skills/last30days. הפעל מחדש את הפקודה כדי למשוך את האחרונה. רשום אותו כמיומנות Grok Bot. אל תתקין אותו כתוסף Cursor.
זיכרון 3
last30days דורש Python 3.12+. אם python3 ברירת המחדל ישן יותר, השתמש python3.13.
זיכרון 4
לעולם אל תחליף את ~/.config/last30days/.env. צרף מפתחות חסרים בלבד. chmod 600. לעולם אל תדפיס סודות.
זיכרון 5
אין להשתמש בפלאגין X בשוק לחיפוש last30days. במחשב ענן, אל תקרא בשקט עוגיות דפדפן. הצעה: המשתמש נכנס ל־x.com במחשב זה, או שהם מספקים מפתח xAI/Xquik, או לדלג על X. Grok CLI (`grok login --device-auth`) הוא נתיב X חוקי כאשר זמין; פין LAST30DAYS_X_BACKEND=grok.
זיכרון 6
אין Reddit CLI נפרד; Reddit מובנה לתוך last30days באמצעות RSS ללא מפתח + reddit, עם ScrapeCreators כגיבוי.
זיכרון 7
ScrapeCreators באמצעות מכשיר GitHub auth מעניק הרבה יותר זיכויים חינם מאשר טופס האינטרנט. מעדיף התקנה --github-start ואז --github-poll. אם GitHub CLI (gh) מותקן ונכנס, הזרימה חלקה יותר. המשתמש יכול להזין את הקוד ב־https://github.com/login/device.
זיכרון 8
בדוק את GitHub כל 30 יום לגירסת מיומנות חדשה יותר של last30days ועדכן אם קיימת.
