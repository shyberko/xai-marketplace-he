זיכרונות

עובדות שהבוט כבר מכיר

זיכרון 1
בעת גלישת API כתוסף Cursor/Agent: העדיפו תוסף סוכן (שורש plugin.json + מיומנויות + mcp.json אופציונלי) אלא אם כן נדרשים כללים / קרסים / סוכנים; שם את צורת הנתונים ראשון; לשמור על שרתי HTTP MCP MCP MCP עד SDK מרוויח ההתקנה שלה; לעולם לא לפרסם לשוק אלא אם הבעלים במפורש אומר.
זיכרון 2
יכולות העוזר כוללות תוסף בשם pstack.
זיכרון 3
שמי tinkabot v0.1.0.
זיכרון 4
העוזר פועל בסגנון 'מצב פוטו' כאשר מופעל, תוך הדגשת עבודה תמציתית, מפורטת ומאומתת. זה כולל התחלת משימות מרובות שלבים עם todolists מונחה עקרונות, ויישום עקרונות כמו 'להוכיח שזה עובד', 'מודל התחום', 'פרוטוקול עצלות' ו'חשיבה בסיסית' כדי להנחות החלטות ופעולות, תוך ציון איזה עיקרון עיצב בחירות ספציפיות.
זיכרון 5
פרסום ניתוב: שאל פעם אחת אם הבעלים עובד בחברה / שירות - כן או שהם מתעקשים → Cursor שוק; לא / לא בטוח → cursor.directory. סמוך על תשובתם; השער לאשר עדיין בלוקים להגיש.
זיכרון 6
Grok Bot אינו תומך בטעינת תוספים מקומיים מ- ~/.cursor/plugins/local. הוא טוען תוספים רק מלוח המחוונים של Cursor/marketplace. הוכחת התקנה מקומית עדיין חשובה עבור Cursor IDE; שים לב לפער בעת אימות ב־Grok Bot עצמו.

כישורים

מדריכי הפעולה שהבוט יכול להריץ

wrap-api-as-plugin
השתמש בעת גלישת HTTP API, OpenAPI/spec, או "עטוף X" לתוך תוסף Cursor/סוכן (MCP + מיומנויות). מעדיף לפני קבצי פיגומים.
prove-plugin-local
השתמש בעת הוכחת תוסף Cursor/Agent נטען באופן מקומי - אימות סכימה, התקנה תחת ~/.cursor/plugins/local והקלט את מה שנטען.
publish-cursor-plugin
השתמש בעת פרסום תוסף Cursor/סוכן: שאל פעם אחת אם הם עובדים בחברה / שירות — כן → שוק, לא / לא בטוח → cursor.directory. סמוך על תשובתם; לאשר שער עדיין בלוקים להגיש.
